# 📱 EPS PRO - Installation GitHub Pages

## 📦 FICHIERS À UPLOADER

Uploadez ces **4 fichiers** dans votre repository GitHub :

1. ✅ `index.html` (l'application)
2. ✅ `manifest.json` (configuration PWA)
3. ✅ `service-worker.js` (mode hors ligne)
4. ✅ `logo.png` (votre logo vert avec les 2 coureurs)

**IMPORTANT :** Renommez votre image en **exactement** `logo.png` (tout en minuscules)

---

## 🔧 CONFIGURATION GITHUB PAGES

1. Allez dans votre repository GitHub
2. Cliquez sur **Settings** (en haut à droite)
3. Dans le menu de gauche, cliquez sur **Pages**
4. Sous **Source**, sélectionnez :
   - Branch : **main** (ou **master**)
   - Folder : **/ (root)**
5. Cliquez sur **Save**
6. **Attendez 1-2 minutes** que GitHub déploie

Votre app sera disponible à :
```
https://[votre-username].github.io/[nom-du-repo]/
```

---

## 📱 INSTALLATION SUR iPad

### **Étape 1 : Ouvrir l'URL dans Safari**
Ouvrez l'URL de votre app dans **Safari** (pas Chrome)

### **Étape 2 : Ajouter à l'écran d'accueil**
1. Appuyez sur le bouton **Partager** 📤 (en haut ou en bas)
2. Faites défiler vers le bas
3. Appuyez sur **"Sur l'écran d'accueil"**
4. Appuyez sur **"Ajouter"**

### **Étape 3 : C'est installé ! ✅**
L'icône **EPS PRO** avec votre logo vert apparaît sur l'écran d'accueil de votre iPad !

## 🆘 PROBLÈMES COURANTS

### **Erreur 404**
- Vérifiez que les 4 fichiers sont bien à la **racine** du repo (pas dans un sous-dossier)
- Vérifiez que `index.html` est bien nommé (tout en minuscules)
- Attendez 1-2 minutes après l'upload

### **Le logo ne s'affiche pas**
- Vérifiez que le fichier image s'appelle **exactement** `logo.png`
- Videz le cache de Safari (Réglages → Safari → Effacer données de site)

### **Le mode hors ligne ne fonctionne pas**
- L'app doit être chargée au moins une fois avec internet
- Le Service Worker s'active après la première visite
